# Screen to Search v0.3.0

Screen to Search now has Windows, Linux, and macOS builds. All three use bundled PP-OCRv6 models for local text recognition.

- **macOS 14+:** New menu bar app with a hold shortcut, darkened fullscreen selection, Smart/Text/Rectangle/Lasso modes, and copy, search, and translate actions. Download `ScreenToSearch-macos-arm64.zip` for Apple Silicon or `ScreenToSearch-macos-x64.zip` for Intel Macs.
- **Linux:** The fullscreen OCR overlay now runs on X11 and other Wayland desktops as well as GNOME and KDE Plasma. X11 can grab F8, F9, or F10 directly. Wayland uses the Global Shortcuts portal when available, or compositor press/release bindings described in the README. Download `ScreenToSearch-linux.zip`.
- **Windows 10/11 x64:** Fresh self-contained package of the current main branch, using the same PP-OCRv6 models. Download `ScreenToSearch-win-x64.zip`.

Extract the complete archive before starting the app. Linux dependencies and desktop bindings, and macOS permission details, are in the [README](https://github.com/SulkBash/ScreenToSearch#readme). The macOS apps are unsigned, so macOS may require you to approve opening them in System Settings. `SHA256SUMS.txt` lists checksums for all four downloads.

Screenshots and OCR stay on your computer. Search and Translate open your browser with the selected text.
