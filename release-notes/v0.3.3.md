# Screen to Search v0.3.3

This release reduces the resources used while Screen to Search waits in the background.

- **Windows:** OCR loads on demand and unloads after 60 seconds without recognition. Settings is created when first opened, keyboard input reuses its native buffer, inference workers sleep between tasks, and large temporary inference buffers are no longer retained in a CPU memory arena. A local, freshly started tray sample fell from 146 MB to 57 MB of resident memory and from 27 threads to 13. Both builds recorded zero CPU time during their 10-second idle samples. These are short measurements on one machine, rather than guarantees for every system or workload.
- **Linux:** The shared OCR engine unloads after 60 seconds without recognition, serializes concurrent recognition requests, uses sleeping inference workers, and avoids retaining an inference memory arena. Tray Settings widgets are built when first opened. Upgrade the Python dependency with `python3 -m pip install "rapidocr>=3.10.0" onnxruntime`.
- **macOS (Apple silicon and Intel):** The packaged shared OCR engine uses the same sleeping workers and low-memory allocator configuration. The existing one-shot helper continues to exit after each request, releasing OCR resources immediately and leaving the menu bar app without a resident OCR engine.

The first recognition after models have been unloaded takes extra time to initialize them. Capture, selection, copy, search, and translate behavior is unchanged. Windows can start automatically through **Settings → Launch at sign-in**; Linux and macOS retain their start-at-login controls.

Added regression checks for lazy initialization, warm reuse, cancellation/failures, stale idle callbacks, automatic unloading, and recognition after reloading. Release packages are built and checked for Windows x64, Linux, macOS arm64, and macOS x64 before publication.

Download your platform archive, extract it, and quit any running copy before launching the new version. Keep the Windows app in a permanent folder before enabling launch at sign-in. See the [README](https://github.com/SulkBash/ScreenToSearch#readme) for setup. `SHA256SUMS.txt` contains archive checksums.
