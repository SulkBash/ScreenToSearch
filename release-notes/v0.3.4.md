# Screen to Search v0.3.4

On Windows, text selection now separates a label from its value when OCR misses the space after a colon. For example, you can select the number in `CLABE: 123456789123456789` without including the label. This also applies to other labels and alphanumeric values. Times such as `12:30` and standard URLs remain intact.

This release also includes the animated Windows walkthrough added to the README. Linux and macOS packages are refreshed; the selection fix applies to Windows.

Download the archive for your platform, extract it, and quit any running copy before launching the new version. See the [README](https://github.com/SulkBash/ScreenToSearch#readme) for setup. `SHA256SUMS.txt` contains checksums for the archives.
