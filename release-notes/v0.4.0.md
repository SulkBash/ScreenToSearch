# Screen to Search v0.4.0

Select recognized text more precisely on Windows, macOS, and Linux. Smart mode keeps selection focused on whole words, while Text mode can select individual characters when OCR provides usable character positions. Labels and their values can also be selected separately in more cases, including some fields where OCR misses a space.

The selection layer uses word and character positions from the same OCR pass and indexes word targets for faster pointer lookup. The existing low-background-resource behavior is preserved, including idle OCR unloading where applicable. OCR can still miss or merge text; when positions cannot be aligned reliably, a larger target may remain selectable.

Download the archive for your platform, extract it, and quit any running copy before launching the new version. See the [README](https://github.com/SulkBash/ScreenToSearch#readme) for setup. `SHA256SUMS.txt` contains checksums for the archives.
