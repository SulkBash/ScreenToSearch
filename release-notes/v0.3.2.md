# Screen to Search v0.3.2

On Windows, the hold shortcut now uses background Raw Input as a fallback when a fullscreen game does not deliver the shortcut through the keyboard hook. This fixes opening the grey selection overlay over fullscreen Factorio; the shortcut, selection, copy, search, and translate flow stays the same. The fix was checked in fullscreen Factorio.

Download the archive for your platform, extract it, and quit any running copy of Screen to Search before launching the new one. The Windows package remains a compact executable alongside the PP-OCRv6 models and licenses. Linux and macOS packages are refreshed for this release.

See the [README](https://github.com/SulkBash/ScreenToSearch#readme) for platform setup. `SHA256SUMS.txt` contains checksums for the archives.
