# Screen to Search v0.1.0

First Windows release. Select text or an image anywhere on your screen, including apps that do not allow normal text selection.

- Local OCR with automatic or selected recognition language; screenshots are not uploaded.
- Smart, Text, Rectangle, and Lasso selection modes.
- Copy selected text or image, search selected text, or open it in Google Translate.
- Tray app with a configurable hold shortcut and optional launch at sign-in.

Download `ScreenToSearch-win-x64.zip`, extract the entire archive, then run `ScreenToSearch.exe`. It supports Windows 10 and 11 on x64 and includes the .NET runtime. Keep the `models` folder beside the executable.

Search and Translate open your browser with the selected text. OCR may miss small or low-contrast text; protected content may appear blank in a capture.
