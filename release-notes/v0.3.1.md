# Screen to Search v0.3.1

The Windows download now bundles its .NET and WPF dependencies into one executable. The extracted package contains the executable, three PP-OCRv6 model files, and license files. Extract the zip and run `ScreenToSearch.exe` as before; no separate .NET installation is needed.

Linux still uses a small `linux` folder with scripts and models. On macOS, Finder shows the extracted `Screen to Search.app` as one app. Both platform packages are refreshed for v0.3.1.

Download the archive for your platform and check `SHA256SUMS.txt` if you want to verify it. macOS packages are unsigned and may need approval in System Settings. Linux dependencies and desktop setup are listed in the [README](https://github.com/SulkBash/ScreenToSearch#readme).
