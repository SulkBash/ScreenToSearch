# Screen to Search v0.2.0

Screen to Search is now available for Windows and Linux. Both platforms use the bundled PP-OCRv6 models for local text recognition.

- Windows: updated self-contained x64 app with PP-OCRv6 detection and recognition.
- Linux: GNOME and KDE Plasma Wayland app with a resident indicator, hold shortcut, and fullscreen selection overlay. Other Linux desktops have a region-capture window.
- Smart, Text, Rectangle, and Lasso selection; copy text or image, search, and translate.

Download `ScreenToSearch-win-x64.zip` for Windows 10 or 11 on x64, or `ScreenToSearch-linux.zip` for Linux. Extract the entire archive before running the app. Linux installation and dependency instructions are in the included `README.md`. Both archives include the OCR model files. `SHA256SUMS.txt` contains checksums for the downloads.

Screenshots and text recognition stay on your computer. Search and Translate open your browser with the selected text.
